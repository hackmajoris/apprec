AppRec

Record the call. Keep the notes.

AppRec lives in your Mac's menu bar. Pick one app, like Teams, Zoom or a browser tab, and it records that app's sound plus your microphone. When you stop, it writes a transcript and a summary, and names the file after what was said.

What happens after you press Record

You do one thing: start and stop. Everything else happens on its own, in this order.

  1. During the call

    Record one app

    Only the app you picked is captured, so notification sounds and music from other apps stay out. Your microphone is mixed in.

  2. When you stop

    Save the audio

    A normal .m4a file lands in its own folder inside Recordings. Play it from the menu or open it anywhere.

  3. Seconds later

    Write the transcript

    Speech becomes text on your Mac. The language is detected for you, so English, Romanian and dozens more just work.

  4. Right after

    Summarize and rename

    A short summary with key points and action items, and the file is renamed after the topic of the call.

What you get for every recording

One folder per recording, with three plain files inside. No account, no database, nothing locked inside the app.

A summary you can skim in ten seconds

Each summary has the same three parts: the gist, the key points, and who agreed to do what. It's written in the language people spoke in the call.

Pick exactly which app to record

Search your running apps by name and choose one. Calls, browser tabs, video players: if it makes sound, AppRec can record it. Turn the microphone off when you only want the app.

Your calls stay on your Mac

Meetings are private. AppRec is built so nothing has to leave your computer.

Transcription is local

The speech model downloads once (about 630 MB) and then runs offline on Apple silicon. Audio is never uploaded. How it works

Summaries are local too

With the free Ollama app, summaries come from a model running on your Mac, and AppRec can download it for you. Without Ollama, it uses Apple Intelligence on macOS 26, in English.

Plain files you own

Everything is saved in ~/Music/Recordings. Back it up, search it with Spotlight, or delete it. Deleting in AppRec moves the recording's folder to the Trash.

How transcription works

AppRec uses Whisper, OpenAI's open speech recognition model, in a version built for Apple chips. There's no server to set up: the model is a file on your Mac, and AppRec runs it there.

  1. First time only

    Download the model

    The first time a recording is transcribed, AppRec downloads Whisper large-v3 turbo (about 630 MB) from Hugging Face, where Argmax publishes it for Apple's Core ML. The menu shows the download progress. It's saved in ~/Library/Application Support/AppRec and never downloaded again.

  2. First time only

    Prepare it for your Mac

    macOS then optimizes the model for your chip's Neural Engine and GPU. This can take a few minutes, and the menu says so while it happens.

  3. Every recording after that

    Turn speech into text, offline

    AppRec reads the recording, splits it at pauses, recognizes the spoken language and writes transcript.txt next to the audio. No internet connection is needed, and the audio never leaves your Mac.

  • ModelWhisper large-v3 turbo
  • Runs withWhisperKit, on the Neural Engine and GPU
  • DownloadAbout 630 MB, once
  • Stored in~/Library/Application Support/AppRec
  • InternetOnly for the first download
  • LanguagesDetected automatically, about 100 supported
  • SpeedAbout 5 s for a 30 s clip on an M3 Max

Install AppRec

One command with Homebrew, or build it from source with Xcode. AppRec isn't notarized by Apple yet, so Homebrew clears the macOS download warning for you.

What you need

  • macOS15 or later26 recommended: adds Apple Intelligence summaries when Ollama isn't installed
  • MacApple silicon
  • Memory8 GB16 GB or more recommended, for the better summary model
  • DiskAbout 1 GB for the speech modelAbout 10 GB with Ollama and its recommended model
  • SummariesOptionalOllama recommended, for summaries in the language of the recording

The first time you record, macOS asks for permission to capture screen and system audio and to use the microphone. AppRec only captures sound.

With Homebrew

  1. Install
    brew install --cask hackmajoris/apps/apprec
  2. Update to the latest version
    brew upgrade --cask apprec

Or build from source

Needs Xcode 26 or later and takes a few minutes.

  1. Get the code
    git clone https://github.com/hackmajoris/apprec cd apprec
  2. Install the project generator
    brew install xcodegen
  3. Build and copy to /Applications
    make install
